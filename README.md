# VOLLYBALL MANIA

9인제 배구 감독용 **수비 포메이션 시뮬레이터**. 상대 공격 루트(레프트 · 라이트 · 속공 · A속공 · B속공 · BA속공 · 시간차)를 고르면
우리 팀 9명이 기본 위치에서 지정한 수비 위치로 이동하는 모습을 애니메이션으로 보여 줍니다.

- 설치가 필요 없는 웹앱(PWA) — `index.html` 하나로 동작, 홈 화면에 추가하면 전체 화면 앱처럼 실행
- 아이폰 Pro Max 같은 세로로 긴 화면과 갤럭시 폴드 펼침 화면(가로로 넓은 화면) 모두에 맞춰 배치가 바뀜
- **위치 편집** → 선수(1~9번), 상대 세터·공격수, 공격 목표 지점을 손가락으로 끌어 옮긴 뒤 **저장**
- 저장 내용은 기기 브라우저(localStorage)에 보관됨. 한 번 열면 오프라인에서도 실행

## 휴대폰에서 실행하기 (GitHub Pages)

1. GitHub Pages 는 `gh-pages` 브랜치로 게시됨. `main` 에 올리면 `.github/workflows/pages.yml` 이 자동으로 `gh-pages` 에 반영
2. 휴대폰 브라우저에서 `https://lodostheory.github.io/vollyball/` 접속 (반영까지 1~2분)
3. 아이폰: Safari 공유 버튼 → **홈 화면에 추가** / 갤럭시: Chrome 메뉴 → **홈 화면에 추가**

## 화면 보는 법

- 화면 위쪽이 상대 코트, 아래쪽이 우리 코트. 상대는 우리를 마주 보므로 **상대 레프트 공격은 화면 오른쪽**에서 들어옵니다.
- 주황 = 전위(1·2·3), 노랑 = 중위(4·5·6), 하늘 = 후위(7·8·9)
- 점선 원과 점선 = 기본 위치와 이동 경로, 빨간 화살표 = 공격 루트
- 패턴 버튼의 초록 점 = 초기값에서 직접 수정한 패턴
